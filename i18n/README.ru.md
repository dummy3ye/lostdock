# LostDock

**LostDock** — это промышленный кросс-платформенный десктопный инструмент для Google доркинга,
написанный на Python. Он предоставляет визуальный конструктор запросов со всеми операторами
поисковых систем, многодвижковое выполнение с ограничением частоты и ротацией прокси, постоянное
хранение результатов, повторную проверку URL, планировщик дорков, регулярные подсветки и систему
плагинов — всё в нативном интерфейсе PySide6 (Qt), работающем на **Windows, macOS и Linux**.

> Полная документация: [README.md](../README.md)

## Возможности

- **Визуальный конструктор дорков** — комбинируйте ключевые слова, точные фразы, булеву логику
  (`AND`/`OR`/`NOT`), исключения, обязательные слова, сайты, типы файлов и все операторы Google
  с предпросмотром в реальном времени.
- **Несколько движков** — адаптеры Google, DuckDuckGo и Bing за единым интерфейсом.
- **Ограничение частоты и антиблокировка** — token-bucket лимитер с джиттером, ротация
  User-Agent, повторные попытки с backoff и детекция CAPTCHA/ботов.
- **Ротация прокси** — пул прокси с ротацией round-robin, кулдауном при ошибках и валидацией.
- **Постоянное хранение** — каждая задача и результат в SQLite, дедупликация между движками.
- **Повторная проверка URL** — заново загружает URL и аннотирует код статуса / тип контента / заголовок.
- **Планировщик дорков** — выполняет сохранённые дорки в фоне по расписанию.
- **Регулярная подсветка** — мгновенно подсвечивает строки, совпадающие с шаблоном.
- **Фильтры** — белый/чёрный список доменов и фильтры по URL-шаблонам (при экспорте).
- **Экспорт** — JSON, CSV, Markdown и стильный автономный HTML-отчёт.
- **Библиотека дорков** — сохраняйте, загружайте и удаляйте дорки по имени.
- **Система плагинов** — Python-модули в `~/.lostdock/plugins/` с хуками `setup`, `on_result`, `on_export`.
- **Кроссплатформенность** — единый код, упакованный для Windows (`.exe`), macOS (`.app`) и Linux.

## Быстрое использование

1. Соберите запрос: ключевые слова, точная фраза, исключения, слова `AND`/`OR`, сайты (`site:`),
   типы файлов и inline-операторы.
2. Выберите движок и число страниц.
3. Нажмите **Run Search** — результаты поступают в таблицу и сохраняются в SQLite.
4. Используйте **Re-check URLs** для проверки статуса каждого результата в реальном времени.
5. Задайте **Highlight**-шаблон для выделения интересных строк.
6. Нажмите **Export...**, чтобы сохранить в JSON, CSV, Markdown или HTML.

## Поддерживаемые операторы

`site:` · `inurl:` · `allinurl:` · `intitle:` · `allintitle:` · `intext:` · `allintext:` · `inanchor:` ·
`filetype:` · `ext:` · `cache:` · `link:` · `related:` · `info:` · `define:` · `author:` · `daterange:` ·
`numrange:` · `loc:` · `after:` · `before:` · `lang:` · точная фраза `"..."` · исключение `-term` ·
синоним `~term` · подстановочный знак `*` · `term1 OR term2`.

## Прокси

Настройте в **Tools → Settings**, по одному на строку:

```
http://127.0.0.1:8080
socks5://127.0.0.1:1080
```

## Планировщик дорков

1. Сохраните дорк (укажите имя в поле «Dork name»).
2. В **Tools → Settings** выберите его и задайте интервал в минутах.
3. Планировщик выполнит его в фоне и сохранит результаты как новые задачи.

## Плагины

Поместите файлы `*.py` в `~/.lostdock/plugins/`. Модуль может экспортировать любой набор хуков:

```python
NAME = "my_plugin"
def setup(app): ...
def on_result(result): return result   # верните None, чтобы отбросить
def on_export(results, fmt, path): ...
```

## Хранение данных

- **База данных:** `~/.lostdock/lostdock.db` (SQLite)
- **Плагины:** `~/.lostdock/plugins/`

## Installation

> Installation instructions are intentionally provided in English only.

### Prerequisites

- **Python 3.10+** — [python.org](https://www.python.org/downloads/)
- **uv** (fast package manager) — [docs.astral.sh/uv](https://docs.astral.sh/uv/getting-started/installation/)

### Steps

```bash
# 1. Clone the repository
git clone https://github.com/your-user/lostdock.git
cd lostdock

# 2. Create a virtual environment and install
uv venv
uv pip install -e ".[dev]"

# 3. Run
uv run lostdock
```

If you do not have `uv`, you can use plain `pip`:

```bash
python3 -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -e ".[dev]"
lostdock
```

## Отказ от ответственности

LostDock — это **инструмент для исследований в области безопасности и OSINT**. Используйте его только
против систем, которые вам принадлежат или для тестирования которых вы получили явное разрешение.
Уважайте условия использования поисковых систем, держите частоту низкой, ответственно используйте
прокси и никогда не применяйте инструмент для несанкционированного доступа, сбора личных данных или
противозаконной деятельности.
